# 预研汇报 PPT 数据

## 目的

本目录收集线程池闭环控制预研项目的汇报数据，按叙事结构组织，方便后续 PPT 制作。

## 使用方式

1. 打开 `ppt-data.md` 按 9 个叙事章节定位所需数据
2. 每章包含：量化数据、对比表格、关键结论、数据来源引用
3. 数据标注了来源（版本号/文档名/行号），可追溯验证

## 叙事结构

```
00-预研价值总览    → 16个实验的12组量化证据 + 已排除风险 + Phase 1启动建议
01-问题发现       → 现网线程池静态配置的 5 个痛点
02-团队头脑风暴    → 4 条技术路线的对比与选型理由
03-提出解决方案    → 闭环控制架构 + 三维调整 + 三层安全
04-进行测试       → 四层测试策略 + 累计测试规模
05-获取数据       → 16个实验的完整数据（基础+现网+运维维度）
06-落地效果       → 28项验证结论
07-与传统方案比较  → 12 个维度的对比表
08-方案落地计划    → 4 阶段路线图 + Phase 1启动条件
09-后续发展       → 优先级排序的待办清单
```

## 数据来源

- **对照实验数据**: `src/test/java/.../experiment/ExperimentDataCollectionTest.java` — 16 个对照实验
  - 实验 1-4: 基础对比（多负载、静态vs自适应、队列容量、线程效率）
  - 实验 5-10: 现网维度（延迟分布、长期稳定性、响应速度、阻塞恢复、混合负载、振荡分析）
  - 实验 11-16: 运维维度（排队vs执行时间、持续过载退化、内存开销、拒绝策略、队列类型、参数敏感性）
- **实验可复现**: `./mvnw test -Dtest="com.zhiwu.dynamicthreadpollermanager.experiment.ExperimentDataCollectionTest" -DfailIfNoTests=false`
- 版本演进总览: `docs/00-project/current-state.md`
- 架构设计: `docs/01-architecture/`
- 复盘细节: `docs/08-retrospectives/`
- v0.16.0 需求与设计: `docs/04-development/versions/v0.16.0/`
