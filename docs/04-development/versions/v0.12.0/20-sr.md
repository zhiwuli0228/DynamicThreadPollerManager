## 1. 设计目标

v0.12.0 SR 将已闭环 IR 转成后续 OpenSpec change 可执行的功能设计。目标：在 v0.3.0 的 baseline executor 基础设施、v0.7.0 的 ManagedExecutor 域和 v0.11.0 的持久化录制基础上，实现 baseline executor 预设目录（`BaselineExecutorCatalog` + `CommonExecutorPreset`）、可比较场景运行器（`ComparableScenarioRunner`）、归一化度量模型（`NormalizedComparisonMetrics` + `ComparisonResult` + `MetricDelta`）、以及比较报告产物（`ComparisonReportArtifact` + `ComparisonJsonWriter`）。同时为 `ManagedExecutor` 添加拒绝计数以支撑比较框架的可靠性维度。

关键架构约束：所有新组件位于 `experiment.scenario` 包（预设 + 比较运行器 + 比较结果模型），仅 `ComparisonJsonWriter` 位于 `experiment.acquisition` 包（复用 `AcquisitionJsonWriter` 手写 JSON 模式）。`ManagedExecutor` rejection counting 是 `experiment.executor` 包的最小变更。

本设计只描述功能边界和组件契约，不授权 Java 实现，不授权 OpenSpec change 创建。

## 2. 设计结论

- **CommonExecutorPreset**: record，放入 `experiment.scenario`，标准化 executor 预设描述
- **BaselineExecutorCatalog**: 放入 `experiment.scenario`，6 个默认预设的注册表，不可变
- **NormalizedComparisonMetrics**: record，放入 `experiment.scenario`，9 个归一化指标 + `fromSnapshots()` 工厂方法
- **MetricDelta**: record，放入 `experiment.scenario`，单指标比较 delta（absolute + relative + direction）
- **ComparisonResult**: record，放入 `experiment.scenario`，完整比较结果（两组 outcome + metrics + deltas）
- **ComparableScenarioRunner**: 放入 `experiment.scenario`，`compare()` 内部动态创建 runner 实例，顺序执行 baseline → managed
- **ComparisonReportArtifact**: record，放入 `experiment.scenario`，比较报告产物
- **ComparisonJsonWriter**: 放入 `experiment.acquisition`，手写 JSON 序列化/反序列化
- **AcquisitionReportPaths 扩展**: comparison 报告文件路径
- **ManagedExecutor 拒绝计数**: `getRejectedTaskCount()` + `AtomicLong` + handler 包装器
- 现有 646 测试零回归

### 关键架构裁决

**Why all comparison types in scenario**: `CommonExecutorPreset` 扩展 `BaselineExecutorPreset` 的概念，`ComparableScenarioRunner` 协调 `ScenarioExperimentRunner` + `ManagedExecutorScenarioRunner`，`NormalizedComparisonMetrics` 从 scenario 收集的快照计算。所有这些是 scenario 包的职责 — 它们定义 experiment/scenario 的"比较维度"，不修改核心 metrics/executor 基础设施。

**Why ComparisonJsonWriter in acquisition**: 复用 `AcquisitionJsonWriter` 的手写 JSON 模式（静态 `render(Object)` 方法）。`AcquisitionJsonWriter` 是 package-private，`ComparisonJsonWriter` 需要在同一包才能复用。遵循 v0.11.0 的先例（`FileBackedEvidenceRecorder` 放入 acquisition 使用 `AcquisitionJsonWriter.render()`）。

**Why not a shared ComparisionJsonWriter in scenario**: 如果放入 scenario，要么 (a) 提升 `AcquisitionJsonWriter` 为 public（打破封装），要么 (b) 在 scenario 中重新实现 JSON 序列化（重复代码）。放入 acquisition 并 import scenario record 类型是最小阻力的路径。

## 4. 组件设计

### 4.1 CommonExecutorPreset

**包**: `com.zhiwu.dynamicthreadpollermanager.experiment.scenario`

**职责**: 标准化通用 executor 预设描述 — 扩展 `BaselineExecutorPreset` 的概念为可分类、可描述的 record。

```java
// 已验证 API 签名:
//   BaselineExecutorPreset(String policyId, int corePoolSize, int maximumPoolSize, int queueCapacity)
//   BaselineExecutorPreset.policyId() → String, corePoolSize() → int,
//     maximumPoolSize() → int, queueCapacity() → int
//   BaselineExecutorPreset.fixedSmall() → BaselineExecutorPreset

public record CommonExecutorPreset(
        String presetId,         // "fixed-4" / "cached" / "single"
        String executorType,     // "FIXED_THREAD_POOL" / "CACHED_THREAD_POOL" / "SINGLE_THREAD_EXECUTOR"
        int corePoolSize,
        int maxPoolSize,
        int queueCapacity,       // -1 = unbounded, 0 = SynchronousQueue, >0 = bounded
        String description       // nullable — 人类可读描述
) {
    private static final Set<String> VALID_TYPES = Set.of(
            "FIXED_THREAD_POOL", "CACHED_THREAD_POOL", "SINGLE_THREAD_EXECUTOR");

    public CommonExecutorPreset {
        java.util.Objects.requireNonNull(presetId, "presetId must not be null");
        if (presetId.isBlank()) {
            throw new IllegalArgumentException("presetId must not be blank");
        }
        java.util.Objects.requireNonNull(executorType, "executorType must not be null");
        if (!VALID_TYPES.contains(executorType)) {
            throw new IllegalArgumentException(
                    "executorType must be one of " + VALID_TYPES + ", was " + executorType);
        }
        if (corePoolSize < 0) {
            throw new IllegalArgumentException("corePoolSize must be >= 0, was " + corePoolSize);
        }
        if (maxPoolSize < corePoolSize) {
            throw new IllegalArgumentException(
                    "maxPoolSize must be >= corePoolSize, was " + maxPoolSize);
        }
        if (queueCapacity < -1) {
            throw new IllegalArgumentException("queueCapacity must be >= -1, was " + queueCapacity);
        }
    }

    /**
     * 转换为 BaselineExecutorPreset (F04 fix: queueCapacity 映射规则)。
     * -1 → Integer.MAX_VALUE (unbounded), 0 → 0, >0 → direct
     */
    public BaselineExecutorPreset toBaselinePreset() {
        int mappedQueue = queueCapacity == -1 ? Integer.MAX_VALUE : queueCapacity;
        return new BaselineExecutorPreset(presetId, corePoolSize, maxPoolSize, mappedQueue);
    }
}
```

设计决策：
- record 而非 class — 纯数据载体，不可变
- `executorType` 限定为 3 个字符串常量（非 enum — 保持简单，外延可扩展但非本次范围）
- `queueCapacity` 使用 -1 表示无界（JDK `LinkedBlockingQueue(Integer.MAX_VALUE)` 的实际语义是无限容量但 `remainingCapacity()` 返回 `Integer.MAX_VALUE - size()` — 用 -1 区分"语义无界"与"恰好 Integer.MAX_VALUE 且剩余容量可查询"）
- `toBaselinePreset()` 执行 F04 fix 的转换：-1 → Integer.MAX_VALUE
- 符合 `decision-log.md` D6（复用 ScenarioDefinition，无新 workload 类型）

### 4.2 BaselineExecutorCatalog

**包**: `com.zhiwu.dynamicthreadpollermanager.experiment.scenario`

**职责**: 注册和管理多个 `CommonExecutorPreset`，提供默认 JDK 标准预设集。

```java
// 已验证 API 签名: 无特殊依赖 — 纯内存注册表，不可变

public final class BaselineExecutorCatalog {

    private final Map<String, CommonExecutorPreset> presets;

    private BaselineExecutorCatalog(Map<String, CommonExecutorPreset> presets) {
        this.presets = Map.copyOf(presets);  // 不可变快照
    }

    public CommonExecutorPreset get(String presetId) {
        java.util.Objects.requireNonNull(presetId, "presetId must not be null");
        CommonExecutorPreset preset = presets.get(presetId);
        if (preset == null) {
            throw new java.util.NoSuchElementException(
                    "no preset for id: " + presetId);
        }
        return preset;
    }

    public Set<String> presetIds() {
        return presets.keySet();
    }

    public int size() {
        return presets.size();
    }

    // ----- Builder (内部使用) -----

    public static final class Builder {
        private final Map<String, CommonExecutorPreset> presets = new java.util.LinkedHashMap<>();

        public Builder register(CommonExecutorPreset preset) {
            java.util.Objects.requireNonNull(preset, "preset must not be null");
            if (presets.containsKey(preset.presetId())) {
                throw new IllegalArgumentException(
                        "duplicate presetId: " + preset.presetId());
            }
            presets.put(preset.presetId(), preset);
            return this;
        }

        public BaselineExecutorCatalog build() {
            return new BaselineExecutorCatalog(new java.util.LinkedHashMap<>(presets));
        }
    }

    // ----- 默认预设集 -----

    public static BaselineExecutorCatalog withDefaults() {
        return new Builder()
                .register(new CommonExecutorPreset(
                        "fixed-2", "FIXED_THREAD_POOL", 2, 2, -1,
                        "Fixed thread pool with 2 threads, unbounded queue"))
                .register(new CommonExecutorPreset(
                        "fixed-4", "FIXED_THREAD_POOL", 4, 4, -1,
                        "Fixed thread pool with 4 threads, unbounded queue"))
                .register(new CommonExecutorPreset(
                        "fixed-8", "FIXED_THREAD_POOL", 8, 8, -1,
                        "Fixed thread pool with 8 threads, unbounded queue"))
                .register(new CommonExecutorPreset(
                        "cached", "CACHED_THREAD_POOL", 0, Integer.MAX_VALUE, 0,
                        "Cached thread pool with SynchronousQueue, unbounded thread creation"))
                .register(new CommonExecutorPreset(
                        "single", "SINGLE_THREAD_EXECUTOR", 1, 1, -1,
                        "Single-thread executor with unbounded queue"))
                .register(new CommonExecutorPreset(
                        "fixed-2-bounded", "FIXED_THREAD_POOL", 2, 2, 10,
                        "Fixed thread pool with 2 threads and bounded queue (capacity=10)"))
                .build();
    }
}
```

设计决策：
- Builder 模式 — `register()` 不可变构造，构建后 preset 集合不可修改
- `withDefaults()` 返回 6 个预设
- `get()` 不存在时返回 `NoSuchElementException`（非 null）
- `Map.copyOf()` 确保不可变 — 防御性拷贝
- 不依赖外部配置文件或数据库

### 4.3 NormalizedComparisonMetrics

**包**: `com.zhiwu.dynamicthreadpollermanager.experiment.scenario`

**职责**: 跨 executor 类型的归一化度量 record，可从 `List<ObservedSnapshot>` 计算。

```java
// 已验证 API 签名:
//   ObservedSnapshot.snapshot() → PressureSnapshot
//   PressureSnapshot.activeThreads() → int, poolSize() → int, queueSize() → int,
//     completedTaskCount() → long
//   ObservedSnapshot.observation() → RuntimeObservation
//   RuntimeObservation.activeThreads() → MetricValue<Integer>, poolSize() → MetricValue<Integer>,
//     queueSize() → MetricValue<Integer>, completedTaskCount() → MetricValue<Long>
//   MetricValue.isPresent() → boolean, MetricValue.Present.value() → T

public record NormalizedComparisonMetrics(
        long completedTaskCount,
        long rejectedTaskCount,
        double avgQueueDepth,
        int maxQueueDepth,
        long totalDurationMs,
        double throughputPerSecond,
        double avgActiveThreads,
        int maxPoolSize,
        int snapshotCount
) {
    /**
     * 从快照列表计算归一化度量。
     *
     * @param snapshots 快照列表（可为空）
     * @param totalDurationMs 总 wall-clock 运行时长（F06 fix: 外部计时）
     * @param fallbackPoolSize 仅在 snapshot 列表为空时使用作为 maxPoolSize 的返回值。
     *                         当 snapshot 非空时，maxPoolSize 从 PressureSnapshot.poolSize() 计算（F05 fix）。
     */
    public static NormalizedComparisonMetrics fromSnapshots(
            List<com.zhiwu.dynamicthreadpollermanager.experiment.metrics.ObservedSnapshot> snapshots,
            long totalDurationMs,
            int fallbackPoolSize) {

        java.util.Objects.requireNonNull(snapshots, "snapshots must not be null");

        if (snapshots.isEmpty()) {
            return new NormalizedComparisonMetrics(
                    0L, 0L, 0.0, 0, totalDurationMs, 0.0, 0.0, fallbackPoolSize, 0);
        }

        int count = snapshots.size();

        // completedTaskCount: 从最后一个 snapshot 的 PressureSnapshot 获取
        com.zhiwu.dynamicthreadpollermanager.experiment.model.PressureSnapshot last =
                snapshots.get(count - 1).snapshot();
        long completed = last.completedTaskCount();

        // rejectedTaskCount: 从 runner 注入（不在 snapshot 中），调用方传入或默认为 0
        long rejected = 0L;  // 由 ComparableScenarioRunner 覆盖

        // avgQueueDepth + maxQueueDepth: 从 PressureSnapshot.queueSize()
        double avgQueue = 0.0;
        int maxQueue = 0;
        for (var s : snapshots) {
            int qs = s.snapshot().queueSize();
            avgQueue += qs;
            if (qs > maxQueue) maxQueue = qs;
        }
        avgQueue /= count;

        // avgActiveThreads: 从 PressureSnapshot.activeThreads()
        double avgActive = 0.0;
        for (var s : snapshots) {
            avgActive += s.snapshot().activeThreads();
        }
        avgActive /= count;

        // maxPoolSize: 从 PressureSnapshot.poolSize()
        int maxPool = fallbackPoolSize;
        for (var s : snapshots) {
            int ps = s.snapshot().poolSize();
            if (ps > maxPool) maxPool = ps;
        }

        // throughput: completedTaskCount / (totalDurationMs / 1000.0)
        double throughput = totalDurationMs > 0
                ? (double) completed / (totalDurationMs / 1000.0)
                : 0.0;

        return new NormalizedComparisonMetrics(
                completed, rejected, avgQueue, maxQueue,
                totalDurationMs, throughput, avgActive, maxPool, count);
    }

    /**
     * 用于 managed executor — rejectedTaskCount 从 ManagedExecutor 读取。
     * 此重载由 ComparableScenarioRunner 在 managed run 后调用。
     */
    public NormalizedComparisonMetrics withRejectedTaskCount(long rejected) {
        return new NormalizedComparisonMetrics(
                completedTaskCount, rejected, avgQueueDepth, maxQueueDepth,
                totalDurationMs, throughputPerSecond, avgActiveThreads,
                maxPoolSize, snapshotCount);
    }
}
```

设计决策：
- `rejectedTaskCount` 默认为 0（baseline executor 从不拒绝）。managed executor 通过 `withRejectedTaskCount()` 补充
- `fallbackPoolSize` 在 snapshot 为空或所有 poolSize 为 0 时使用 — baseline executor 的 `poolSize()` 返回 `preset.corePoolSize()`（非 0）
- `throughputPerSecond` 在 `totalDurationMs == 0` 时返回 0.0（不除零）
- F06 fix: `totalDurationMs` 由 `ComparableScenarioRunner` 在 run 前后 wall-clock 计时，不从此方法内部推断
- 所有聚合从 `PressureSnapshot` 字段计算（非 `RuntimeObservation`），因为 `PressureSnapshot` 值均为 primitive（无 MetricValue 的 Optional 语义）

### 4.4 MetricDelta

**包**: `com.zhiwu.dynamicthreadpollermanager.experiment.scenario`

```java
public record MetricDelta(
        String metricName,
        double baselineValue,
        double managedValue,
        double absoluteDelta,     // managedValue - baselineValue
        double relativeDelta,     // (managedValue - baselineValue) / baselineValue * 100.0
        String direction          // "IMPROVED" / "REGRESSED" / "NEUTRAL"
) {
    public MetricDelta {
        java.util.Objects.requireNonNull(metricName, "metricName must not be null");
        java.util.Objects.requireNonNull(direction, "direction must not be null");
    }

    /**
     * 计算单指标 delta。
     * direction 判断规则:
     *   - throughputPerSecond: managed > baseline → IMPROVED
     *   - avgQueueDepth, maxQueueDepth, rejectedTaskCount: managed < baseline → IMPROVED
     *   - totalDurationMs: managed < baseline → IMPROVED
     *   - 其余: 由调用方指定 (trend-sensitive)
     *   - 相对变化绝对值 < 1% → NEUTRAL
     */
    public static MetricDelta compute(
            String metricName,
            double baselineValue,
            double managedValue,
            boolean higherIsBetter) {

        double absDelta = managedValue - baselineValue;
        double relDelta = baselineValue != 0.0
                ? (absDelta / baselineValue) * 100.0
                : 0.0;

        String dir;
        if (Math.abs(relDelta) < 1.0) {
            dir = "NEUTRAL";
        } else if (higherIsBetter) {
            dir = absDelta > 0 ? "IMPROVED" : "REGRESSED";
        } else {
            dir = absDelta < 0 ? "IMPROVED" : "REGRESSED";
        }

        return new MetricDelta(metricName, baselineValue, managedValue, absDelta, relDelta, dir);
    }
}
```

设计决策：
- `compute()` 静态工厂 — 单一来源，避免 delta 计算逻辑分散
- `higherIsBetter` flag 决定 direction 语义（避免在 ComparisonResult 中硬编码指标名称 → direction 映射）
- NEUTRAL 阈值 1%（IR-v0.12-003 规定）
- `baselineValue == 0` 时 `relativeDelta = 0.0`（IR-v0.12-005 要求）

### 4.6 ComparableScenarioRunner

**包**: `com.zhiwu.dynamicthreadpollermanager.experiment.scenario`

**职责**: 接受 scenario + baseline presetId + ManagedExecutorConfig，依次运行 baseline 和 managed，产出 ComparisonResult。

```java
// 已验证 API 签名:
//   ExperimentCoordinator 构造器: ExperimentCoordinator() — 无参
//   ExperimentCoordinator.createRun(String scenarioId, String policyId) → ExperimentRun
//   ExperimentCoordinator.startRun(String runId), stopRun(String runId), finalizeRun(String runId)
//   ScenarioPlanner.plan(ScenarioDefinition) → ScenarioPlan
//   ScenarioExperimentRunner(ExperimentCoordinator, ScenarioPlanner,
//       BaselineWorkloadExecutor, PressureSampler, EvidenceRecorder, Supplier<Instant>)
//   ScenarioExperimentRunner.run(ScenarioDefinition, BaselineExecutorPreset) → ScenarioRunOutcome
//   ManagedExecutorScenarioRunner(ExperimentCoordinator, ScenarioPlanner,
//       PressureSampler, EvidenceRecorder, Supplier<Instant>)
//   ManagedExecutorScenarioRunner(ExperimentCoordinator, ScenarioPlanner,
//       PressureSampler, EvidenceRecorder, Supplier<Instant>, LivePressureSamplerConfig)
//   ManagedExecutorScenarioRunner.run(ScenarioDefinition, ManagedExecutorConfig) → ScenarioRunOutcome
//   EvidenceRecorder.snapshots(String runId) → List<ObservedSnapshot>
//   BaselineExecutorPreset(BaselineExecutorPreset preset) — 构造器
//   BaselineWorkloadExecutor(BaselineExecutorPreset preset) — 构造器
//   ManualPressureSampler(SnapshotAssembler) — 构造器
//   DefaultSnapshotAssembler() — 无参构造器

public final class ComparableScenarioRunner {

    private final BaselineExecutorCatalog catalog;
    private final ScenarioPlanner planner;
    private final java.util.function.Supplier<java.time.Instant> clock;

    public ComparableScenarioRunner(
            BaselineExecutorCatalog catalog,
            ScenarioPlanner planner,
            java.util.function.Supplier<java.time.Instant> clock) {
        this.catalog = java.util.Objects.requireNonNull(catalog);
        this.planner = java.util.Objects.requireNonNull(planner);
        this.clock = java.util.Objects.requireNonNull(clock);
    }

    /**
     * 执行 baseline vs managed 比较 (F01 fix: 精确数据流)。
     *
     * 每次调用动态创建 runner 实例 (F05 fix)。
     */
    public ComparisonResult compare(
            ScenarioDefinition scenario,
            String baselinePresetId,
            com.zhiwu.dynamicthreadpollermanager.experiment.executor.ManagedExecutorConfig managedConfig) {

        java.util.Objects.requireNonNull(scenario, "scenario must not be null");
        java.util.Objects.requireNonNull(baselinePresetId, "baselinePresetId must not be null");
        java.util.Objects.requireNonNull(managedConfig, "managedConfig must not be null");

        // Step 1: 获取 + 转换 preset
        CommonExecutorPreset preset = catalog.get(baselinePresetId);
        BaselineExecutorPreset bPreset = preset.toBaselinePreset();

        // Step 2-3: Baseline run (F01 fix: 完整数据流)
        com.zhiwu.dynamicthreadpollermanager.experiment.coordinator.ExperimentCoordinator bCoord =
                new com.zhiwu.dynamicthreadpollermanager.experiment.coordinator.ExperimentCoordinator();
        com.zhiwu.dynamicthreadpollermanager.experiment.metrics.InMemoryEvidenceRecorder bRecorder =
                new com.zhiwu.dynamicthreadpollermanager.experiment.metrics.InMemoryEvidenceRecorder();

        long baselineEndMs = clock.get().toEpochMilli();

        java.util.List<com.zhiwu.dynamicthreadpollermanager.experiment.metrics.ObservedSnapshot>
                bSnapshots = bRecorder.snapshots(bOutcome.runId());
        NormalizedComparisonMetrics bMetrics = NormalizedComparisonMetrics.fromSnapshots(
                bSnapshots, baselineEndMs - baselineStartMs, bPreset.corePoolSize());

        // Step 4-5: Managed run (F01 fix: 完整数据流)
        com.zhiwu.dynamicthreadpollermanager.experiment.coordinator.ExperimentCoordinator mCoord =

        deltas.put("maxQueueDepth", MetricDelta.compute(

                mMetrics.maxQueueDepth(), false));
        deltas.put("totalDurationMs", MetricDelta.compute(

                mMetrics.totalDurationMs(), false));

                "throughputPerSecond", bMetrics.throughputPerSecond(),
                mMetrics.throughputPerSecond(), true));
        deltas.put("avgActiveThreads", MetricDelta.compute(
                "avgActiveThreads", bMetrics.avgActiveThreads(),
                mMetrics.avgActiveThreads(), true));
        deltas.put("maxPoolSize", MetricDelta.compute(
                "maxPoolSize", bMetrics.maxPoolSize(),
                mMetrics.maxPoolSize(), true));
        deltas.put("snapshotCount", MetricDelta.compute(
                "snapshotCount", bMetrics.snapshotCount(),
                mMetrics.snapshotCount(), true));

        // Step 8: Return
        String comparisonId = java.util.UUID.randomUUID().toString();
        return new ComparisonResult(
                comparisonId, scenario.scenarioId(),
                baselinePresetId, managedConfig.toPresetSummary().policyId(),
```

设计决策：
- **F01 fix**: 完整 8 步数据流 — preset 获取 → baseline run → snapshots → metrics → managed run → snapshots → metrics → deltas
- **F05 fix**: `compare()` 内部动态创建所有 runner 实例（不持有单一实例）
- 每个 run 使用独立的 `ExperimentCoordinator` + `InMemoryEvidenceRecorder`（通过 outcome.runId() 从 recorder 获取 snapshots）
- baseline run 的 `completedTaskCount` 从 `baselineExecutor.completedWorkUnits()` 获取 — 映射到 `PressureSnapshot` 不包含此值，但 `NormalizedComparisonMetrics.fromSnapshots()` 从最后一个 snapshot 的 `completedTaskCount` 字段获取。**注意**: `BaselineWorkloadExecutor` 的 `executeStep()` 不设置真实的 completedTaskCount — 需要确认 `ScenarioExperimentRunner.buildObservation()` 如何设置此字段
- managed runner 的 rejectedTaskCount: `ManagedExecutorScenarioRunner.run()` 内部创建 executor 并在 Phase 5 shutdown 后不可访问。此问题需要 SR review 解决

**待解决**: managed executor 拒绝计数的获取路径。`ManagedExecutorScenarioRunner.run()` 创建 executor → 运行 → shutdown → 返回 outcome。ComparableScenarioRunner 无法在 run 完成后访问 executor 的 `getRejectedTaskCount()`。选项：
- A: `ManagedExecutorScenarioRunner` 在 `ScenarioRunOutcome` 中新增 `rejectedTaskCount` 字段
- B: 不修改 outcome，ComparableScenarioRunner 通过 reflection 或 executor registry 获取
- C: `ManagedExecutorScenarioRunner.run()` 在 shutdown 前记录 rejectedTaskCount 到 recorder 或统计对象

**SR recommendation**: 选项 A（最小侵入）。`ScenarioRunOutcome` 新增 `long rejectedTaskCount` 字段（默认值 0，向后兼容），`ManagedExecutorScenarioRunner.run()` 在 Phase 4（finalizeRun 后、shutdown 前）设置此值。

```java

public final class ComparisonJsonWriter {

    private final com.zhiwu.dynamicthreadpollermanager.experiment.acquisition.AcquisitionReportPaths paths;

    private String renderArtifact(ComparisonReportArtifact a) {
        StringBuilder sb = new StringBuilder();
        sb.append("{\n");
        sb.append("  \"comparisonId\": \"").append(escape(a.comparisonId())).append("\",\n");
        sb.append("  \"scenarioId\": \"").append(escape(a.scenarioId())).append("\",\n");
        sb.append("  \"createdAt\": \"").append(a.createdAt().toString()).append("\",\n");

        sb.append("}");

    private String renderPreset(CommonExecutorPreset p) {
        return String.format(

                + "\"maxPoolSize\":%d,\"queueCapacity\":%d,\"description\":%s}",
                escape(p.presetId()), escape(p.executorType()),
                p.corePoolSize(), p.maxPoolSize(), p.queueCapacity(),
                p.description() != null ? "\"" + escape(p.description()) + "\"" : "null");

    private String renderManagedConfig(
            com.zhiwu.dynamicthreadpollermanager.experiment.executor.ManagedExecutorConfig c) {
        return String.format(
                "{\"corePoolSize\":%d,\"maximumPoolSize\":%d,\"queueCapacity\":%d,"
                + "\"keepAliveTime\":%d,\"keepAliveTimeUnit\":\"%s\",\"threadMode\":\"%s\"}",
                c.corePoolSize(), c.maximumPoolSize(), c.queueCapacity(),
                c.keepAliveTime(), c.keepAliveTimeUnit().name(), c.threadMode().name());
    }

    private String renderResult(ComparisonResult r) {
        StringBuilder sb = new StringBuilder();
        sb.append("{\n");
        sb.append("    \"comparisonId\": \"").append(escape(r.comparisonId())).append("\",\n");
        sb.append("    \"scenarioId\": \"").append(escape(r.scenarioId())).append("\",\n");
        sb.append("    \"baselineMetrics\": ").append(renderMetrics(r.baselineMetrics())).append(",\n");
        sb.append("    \"managedMetrics\": ").append(renderMetrics(r.managedMetrics())).append(",\n");
        sb.append("    \"deltas\": ").append(renderDeltas(r.deltas())).append("\n");
        sb.append("  }");
        return sb.toString();
    }

    private String renderMetrics(NormalizedComparisonMetrics m) {
        return String.format(
                "{\"completedTaskCount\":%d,\"rejectedTaskCount\":%d,"
                + "\"avgQueueDepth\":%.2f,\"maxQueueDepth\":%d,"
                + "\"totalDurationMs\":%d,\"throughputPerSecond\":%.2f,"
                + "\"avgActiveThreads\":%.2f,\"maxPoolSize\":%d,\"snapshotCount\":%d}",
                m.completedTaskCount(), m.rejectedTaskCount(),
                m.avgQueueDepth(), m.maxQueueDepth(),
                m.totalDurationMs(), m.throughputPerSecond(),
                m.avgActiveThreads(), m.maxPoolSize(), m.snapshotCount());
    }

    private String renderDeltas(java.util.Map<String, MetricDelta> deltas) {
        StringBuilder sb = new StringBuilder();
        sb.append("{\n");
        int i = 0;
        for (var entry : deltas.entrySet()) {
            MetricDelta d = entry.getValue();
            sb.append("      \"").append(escape(entry.getKey())).append("\": ");
            sb.append(String.format(
                    "{\"baselineValue\":%.2f,\"managedValue\":%.2f,"
                    + "\"absoluteDelta\":%.2f,\"relativeDelta\":%.2f,\"direction\":\"%s\"}",
                    d.baselineValue(), d.managedValue(),
                    d.absoluteDelta(), d.relativeDelta(), d.direction()));
            if (++i < deltas.size()) sb.append(",");
            sb.append("\n");
        }
        sb.append("    }");
        return sb.toString();
    }

    // ============================================================
    // 内部: 反序列化 (手写解析器)
    // ============================================================

    @SuppressWarnings("unchecked")
    private ComparisonReportArtifact parseArtifact(String json) {
        // F01 fix: 使用 parse() 而非 render()
        Object parsed = com.zhiwu.dynamicthreadpollermanager.experiment.acquisition.AcquisitionJsonWriter
                .parse(json);
        return ComparisonReportArtifact.fromMap((Map<String, Object>) parsed);
    }

    private static String escape(String s) {
        return s.replace("\\", "\\\\")
                .replace("\"", "\\\"")
                .replace("\n", "\\n")
                .replace("\r", "\\r")
                .replace("\t", "\\t");
    }
}
```
