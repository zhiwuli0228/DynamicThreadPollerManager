### 2.3 ResourceBudget (Class)

```java
public final class ResourceBudget {
    private final int maxTotalThreads;
    private final int maxTotalQueueCapacity; // 0 = unbounded

    // Verified: ConcurrentHashMap used for thread safety
    private final Map<String, Integer> threadAllocations; // executorId → allocated
    private final Map<String, Integer> queueAllocations;  // executorId → allocated

    public ResourceBudget(int maxTotalThreads, int maxTotalQueueCapacity) {
        if (maxTotalThreads < 1) throw new IllegalArgumentException(...);
        if (maxTotalQueueCapacity < 0) throw new IllegalArgumentException(...);
        this.maxTotalThreads = maxTotalThreads;
        this.maxTotalQueueCapacity = maxTotalQueueCapacity;
        // Verified: ConcurrentHashMap constructor — no arguments needed
        this.threadAllocations = new ConcurrentHashMap<>();
        this.queueAllocations = new ConcurrentHashMap<>();
    }

    // Thread-safe: synchronized
    public synchronized int availableThreads() {
        return maxTotalThreads - totalAllocatedThreads();
    }

    public synchronized int totalAllocatedThreads() {
        return threadAllocations.values().stream().mapToInt(Integer::intValue).sum();
    }

    public int allocatedThreads(String executorId) {
        return threadAllocations.getOrDefault(executorId, 0);
    }

    // Returns defensive copy
    public Map<String, Integer> getThreadAllocations() {
        synchronized (this) {
            return Map.copyOf(threadAllocations);
        }
    }

    // Thread-safe: synchronized
    // delta may be negative (scale-down = release)
    public synchronized void reserve(String executorId, int threadDelta) {
        if (threadDelta > 0 && threadDelta > availableThreads()) {
            throw new IllegalStateException(
                "Insufficient threads: requested=" + threadDelta
                + ", available=" + availableThreads());
        }
        int current = threadAllocations.getOrDefault(executorId, 0);
        int newAlloc = current + threadDelta;
        if (newAlloc < 0) {
            throw new IllegalStateException(
                "Cannot release more than allocated: allocated=" + current
                + ", delta=" + threadDelta);
        }
        if (newAlloc == 0) {
            threadAllocations.remove(executorId);
        } else {
            threadAllocations.put(executorId, newAlloc);
        }
    }

    public synchronized void release(String executorId, int amount) {
        reserve(executorId, -amount); // release = negative reserve
    }

    /** Snapshot for history recording — returns a copy with same allocations. */
    public ResourceBudget snapshot() {
        ResourceBudget copy = new ResourceBudget(maxTotalThreads, maxTotalQueueCapacity);
        synchronized (this) {
            copy.threadAllocations.putAll(this.threadAllocations);
            copy.queueAllocations.putAll(this.queueAllocations);
        }
        return copy;
    }
}
```

- `ConcurrentHashMap` — `new ConcurrentHashMap<>()` valid constructor (verified by reading `ExecutorRegistry` uses the same pattern)

### 2.4 GroupCoordinator (Class)

```java
public final class GroupCoordinator {
    private final ExecutorGroupConfig config;
    private final ResourceBudget budget;
    private final GroupCoordinationHistory history;
    private final CrossExecutorOscillationDetector crossDetector;
    // IR disposition P1-02: coordinator holds adapter refs for direct preemption
    private final Map<String, ExecutorAdjustmentAdapter> adapters;
    private final Object lock = new Object(); // coordination serialization lock

    // Verified: ExecutorAdjustmentAdapter interface exists at experiment.adjustment
    public GroupCoordinator(
            ExecutorGroupConfig config,
            ResourceBudget budget,
            GroupCoordinationHistory history,
            CrossExecutorOscillationDetector crossDetector,
            Map<String, ExecutorAdjustmentAdapter> adapters) {
        this.config = Objects.requireNonNull(config);
        this.budget = Objects.requireNonNull(budget);
        this.history = Objects.requireNonNull(history);
        this.crossDetector = Objects.requireNonNull(crossDetector);
        this.adapters = Map.copyOf(Objects.requireNonNull(adapters));
    }

    // IR disposition P0-01: accepts ScaleAdjustmentCommand (not AdjustmentDecision)
    // Verified: ScaleAdjustmentCommand has: targetPoolSize(), currentPoolSize(),
    //   isNoOp(), reason(), sourceDecisionRef(), decisionTimestamp(), runId()
    // SR disposition P1-01: executor identified by explicit name, not pool size matching
    public GroupCoordinationResult coordinate(
            ScaleAdjustmentCommand command, String executorName) {

        Objects.requireNonNull(command, "command must not be null");
        Objects.requireNonNull(executorName, "executorName must not be null");

        String executorId = executorName;
        AdjustmentPriority priority = config.memberPriorities()
                .getOrDefault(executorId, config.defaultPriority());

        synchronized (lock) {
            // Fast path: no-op
            // Verified: ScaleAdjustmentCommand.isNoOp() returns currentPoolSize == targetPoolSize
            if (command.isNoOp()) {
                ResourceBudget before = budget.snapshot();
                GroupCoordinationResult result = new GroupCoordinationResult(
                    command, command, CoordinationOutcome.APPROVED_AS_IS,
                    "no-op command, no resource impact",
                    List.of(), false, clock.get());
                history.record(new GroupCoordinationEntry(
                    executorId, command, result, before, budget.snapshot(), clock.get()));
                return result;
            }

            int currentPoolSize = command.currentPoolSize();
            int targetPoolSize = command.targetPoolSize();
            int delta = targetPoolSize - currentPoolSize;

            ResourceBudget before = budget.snapshot();

            // Scale-down or no change: release and approve
            if (delta <= 0) {
                if (delta < 0) {
                    budget.release(executorId, -delta);
                }
                // Cross-oscillation check (advisory)
                boolean crossOsc = crossDetector.wouldCrossOscillate(
                    command, executorId, history);
                GroupCoordinationResult result = new GroupCoordinationResult(
                    command, command, CoordinationOutcome.APPROVED_AS_IS,
                    "scale-down: released " + (-delta) + " threads",
                    List.of(), crossOsc, clock.get());
                history.record(new GroupCoordinationEntry(
                    executorId, command, result, before, budget.snapshot(), clock.get()));
                return result;
            }

            // Scale-up: check budget
            int available = budget.availableThreads();
            if (available >= delta) {
                budget.reserve(executorId, delta);
                boolean crossOsc = crossDetector.wouldCrossOscillate(
                    command, executorId, history);
                GroupCoordinationResult result = new GroupCoordinationResult(
                    command, command, CoordinationOutcome.APPROVED_AS_IS,
                    "scale-up: reserved " + delta + " threads",
                    List.of(), crossOsc, clock.get());
                history.record(new GroupCoordinationEntry(
                    executorId, command, result, before, budget.snapshot(), clock.get()));
                return result;
            }

            // Budget insufficient: try preemption
            int shortfall = delta - available;
            List<String> preempted = new ArrayList<>();
            int collected = 0;

            // Scan lower-priority executors, lowest first
            List<String> candidates = budget.getThreadAllocations().keySet().stream()
                .filter(id -> !id.equals(executorId))
                .filter(id -> priority.canPreempt(
                    config.memberPriorities().getOrDefault(id, config.defaultPriority())))
                .sorted((a, b) -> {
                    AdjustmentPriority pa = config.memberPriorities()
                        .getOrDefault(a, config.defaultPriority());
                    AdjustmentPriority pb = config.memberPriorities()
                        .getOrDefault(b, config.defaultPriority());
                    return Integer.compare(pa.getLevel(), pb.getLevel()); // lowest first
                })
                .collect(Collectors.toList());

            for (String candidateId : candidates) {
                if (collected >= shortfall) break;
                int allocated = budget.allocatedThreads(candidateId);
                // Preempt down to minimum (ensure at least corePoolSize remains)
                // For safety, preempt at most allocated - 1 (keep minimum 1 thread)
                int preemptible = Math.max(0, allocated - 1);
                int take = Math.min(preemptible, shortfall - collected);
                if (take > 0) {
                    // Direct preemption (IR disposition P1-02)
                    applyPreemption(candidateId, allocated - take,
                        "preempted by " + executorId + " (priority: " + priority + ")");
                    budget.release(candidateId, take);
                    collected += take;
                    preempted.add(candidateId + ":" + take);
                }
            }

            if (collected >= delta) {
                budget.reserve(executorId, delta);
                boolean crossOsc = crossDetector.wouldCrossOscillate(
                    command, executorId, history);
                GroupCoordinationResult result = new GroupCoordinationResult(
                    command, command, CoordinationOutcome.MODIFIED,
                    "preempted " + preempted.size() + " executors: " + preempted,
                    preempted, crossOsc, clock.get());
                history.record(new GroupCoordinationEntry(
                    executorId, command, result, before, budget.snapshot(), clock.get()));
                return result;
            }

            if (collected > 0) {
                // Partial: cap the request
                int cappedTarget = currentPoolSize + collected;
                budget.reserve(executorId, collected);
                // Build capped command
                // Verified: ScaleAdjustmentCommand.create(runId, timestamp, current, target, reason, ref, clock)
                ScaleAdjustmentCommand cappedCommand = ScaleAdjustmentCommand.create(
                    command.runId(),
                    command.decisionTimestamp(),
                    currentPoolSize,
                    cappedTarget,
                    "capped from " + targetPoolSize + " to " + cappedTarget
                        + " (original: " + command.reason() + ")",
                    command.sourceDecisionRef(),
                    clock);
                boolean crossOsc = crossDetector.wouldCrossOscillate(
                    cappedCommand, executorId, history);
                GroupCoordinationResult result = new GroupCoordinationResult(
                    command, cappedCommand, CoordinationOutcome.CAPPED,
                    "capped: requested " + delta + ", granted " + collected
                        + ", preempted: " + preempted,
                    preempted, crossOsc, clock.get());
                history.record(new GroupCoordinationEntry(
                    executorId, command, result, before, budget.snapshot(), clock.get()));
                return result;
            }

            // Nothing available
            boolean crossOsc = crossDetector.wouldCrossOscillate(
                command, executorId, history);
            GroupCoordinationResult result = new GroupCoordinationResult(
                command, command, CoordinationOutcome.REJECTED,
                "budget exhausted: requested " + delta + ", available " + available
                    + ", no preemptible lower-priority executors",
                List.of(), crossOsc, clock.get());
            history.record(new GroupCoordinationEntry(
                executorId, command, result, before, budget.snapshot(), clock.get()));
            return result;
        }
    }

    // IR disposition P1-02: direct adapter invocation for preemption
    private void applyPreemption(String executorId, int newTargetPoolSize, String reason) {
        ExecutorAdjustmentAdapter adapter = adapters.get(executorId);
        if (adapter == null) return; // executor may have been removed
        ScaleAdjustmentCommand preemptCmd = ScaleAdjustmentCommand.create(
            "preempt-" + executorId,
            clock.get(),
            adapter.currentState().corePoolSize(), // Verified: ExecutorStateSnapshot has corePoolSize()
            newTargetPoolSize,
            reason,
            "group-coordinator:preempt:" + executorId,
            clock);
        adapter.apply(preemptCmd); // fire-and-forget; result recorded in executor's history
    }

    public ResourceBudget getBudget() { return budget; }
    public GroupCoordinationHistory getHistory() { return history; }
}
```

```java
// Methods: ExecutorStateSnapshot currentState(), AdjustmentResult apply(ScaleAdjustmentCommand)
public final class CoordinatedAdjustmentAdapter implements ExecutorAdjustmentAdapter {

    private final ExecutorAdjustmentAdapter delegate;
    private final GroupCoordinator coordinator;
    private final ManagedExecutor executor;
    private final String executorName;  // SR disposition P1-01: explicit name
    private final Supplier<Instant> clock;

    public CoordinatedAdjustmentAdapter(
            ExecutorAdjustmentAdapter delegate,
            GroupCoordinator coordinator,
            ManagedExecutor executor,
            String executorName,
            Supplier<Instant> clock) {
        this.delegate = Objects.requireNonNull(delegate);
        this.coordinator = Objects.requireNonNull(coordinator);
        this.executor = Objects.requireNonNull(executor);
        this.executorName = Objects.requireNonNull(executorName);
        if (executorName.isBlank()) throw new IllegalArgumentException("executorName must not be blank");
        this.clock = Objects.requireNonNull(clock);
    }

    @Override
    public ExecutorStateSnapshot currentState() {
        return delegate.currentState(); // no coordination needed for reads
    }

    @Override
    public AdjustmentResult apply(ScaleAdjustmentCommand command) {
        // Step 1: Coordinate with executor name (SR disposition P1-01)
        GroupCoordinationResult result = coordinator.coordinate(command, executorName);

        // Step 2: Handle non-approved outcomes
        if (result.isRejected()) {
            // Verified: AdjustmentResult constructor (10 params):
            // AdjustmentResult(command, status, beforeState, requestedPoolSize,
            //   appliedPoolSize, afterState, reason, failureCode, sourceDecisionRef, decisionTimestamp)
            ExecutorStateSnapshot state = delegate.currentState();
            return new AdjustmentResult(
                command,
                AdjustmentStatus.REJECTED,   // Verified: AdjustmentStatus enum exists
                state,
                command.targetPoolSize(),
                state.corePoolSize(),        // appliedPoolSize = unchanged
                state,                       // afterState = unchanged
                result.rationale(),
                AdjustmentFailureCode.INVALID_COMMAND, // placeholder — SR review: should we add COORDINATION_REJECTED?
                command.sourceDecisionRef(),
                command.decisionTimestamp());
        }

        // Step 3: Apply (possibly capped)
        ScaleAdjustmentCommand toApply = result.outcome() == CoordinationOutcome.CAPPED
            ? result.approvedCommand()
            : command;

        AdjustmentResult applied = delegate.apply(toApply);

        // Step 4: On successful scale-down, release budget
        if (applied.status() == AdjustmentStatus.APPLIED && toApply.targetPoolSize() < toApply.currentPoolSize()) {
            coordinator.getBudget().release(
                executorName, toApply.currentPoolSize() - toApply.targetPoolSize());
        }

        return applied;
    }
}
```

```java
public final class ExecutorGroup {
    private final ExecutorGroupConfig config;
    private final List<ManagedExecutor> members;
    private final ResourceBudget budget;
    private final GroupCoordinator coordinator;
    private final GroupCoordinationHistory history;

    // Verified: ManagedExecutor.getCorePoolSize(), getQueueCapacity() are public
    public ExecutorGroup(
            ExecutorGroupConfig config,
            List<ManagedExecutor> members,
            Map<String, ExecutorAdjustmentAdapter> adapters) {

        this.config = Objects.requireNonNull(config);
        Objects.requireNonNull(members);
        if (members.isEmpty()) throw new IllegalArgumentException("members must not be empty");
        this.members = List.copyOf(members);

        // IR disposition P1-03: construction-time budget validation
        int totalCorePoolSize = members.stream()
            .mapToInt(ManagedExecutor::getCorePoolSize).sum();
        if (totalCorePoolSize > config.maxTotalThreads()) {
            throw new IllegalArgumentException(
                "Total core pool size " + totalCorePoolSize
                + " exceeds budget " + config.maxTotalThreads());
        }
        if (config.maxTotalQueueCapacity() > 0) {
            int totalQueue = members.stream()
                .mapToInt(ManagedExecutor::getQueueCapacity).sum();
            if (totalQueue > config.maxTotalQueueCapacity()) {
                throw new IllegalArgumentException(
                    "Total queue capacity " + totalQueue
                    + " exceeds budget " + config.maxTotalQueueCapacity());
            }
        }

        // Initialize budget with current allocations
        this.budget = new ResourceBudget(
            config.maxTotalThreads(), config.maxTotalQueueCapacity());
        for (ManagedExecutor m : members) {
            this.budget.reserve(identify(m), m.getCorePoolSize());
        }

        this.history = new GroupCoordinationHistory();
        this.coordinator = new GroupCoordinator(
            config, budget, history,
            new CrossExecutorOscillationDetector(8), // window size = 8
            adapters);
    }

    public ExecutorGroupConfig getConfig() { return config; }
    public List<ManagedExecutor> getMembers() { return members; }
    public ResourceBudget getBudget() { return budget; }
    public GroupCoordinator getCoordinator() { return coordinator; }
    public GroupCoordinationHistory getHistory() { return history; }
    public int size() { return members.size(); }

    public boolean contains(String executorId) {
        return members.stream().anyMatch(m -> identify(m).equals(executorId));
    }

    private String identify(ManagedExecutor m) {
        // Use system.identityHashCode or a user-provided name
        // In practice, executors are identified by their registration name in ExecutorRegistry
        return Integer.toHexString(System.identityHashCode(m));
    }
}
```

### 2.9 CrossExecutorOscillationDetector (Class)

```java
public final class CrossExecutorOscillationDetector {
    private final int windowSize;

    public CrossExecutorOscillationDetector(int windowSize) {
        if (windowSize < 4) throw new IllegalArgumentException(
            "windowSize must be >= 4, was " + windowSize);
        this.windowSize = windowSize;
    }

    /**
     * Check if executing the pending command would create a cross-executor
     * oscillation pattern.
     *
     * @param pending     the pending scale-up command
     * @param sourceId    the executor requesting scale-up
     * @param history     group coordination history
     */
    public boolean wouldCrossOscillate(
            ScaleAdjustmentCommand pending,
            String sourceId,
            GroupCoordinationHistory history) {

        // Verified: ScaleAdjustmentCommand.targetPoolSize(), currentPoolSize() are int accessors
        int pendingDelta = pending.targetPoolSize() - pending.currentPoolSize();
        if (pendingDelta <= 0) return false; // scale-downs don't oscillate

        List<GroupCoordinationEntry> recent = history.recent(windowSize);
        if (recent.size() < 2) return false;

        // Pattern 1: Lockstep counter-adjustment
        // source scales up while another executor recently scaled down by similar magnitude
        Map<String, List<Integer>> deltasByExecutor = new LinkedHashMap<>();
        for (GroupCoordinationEntry entry : recent) {
            int delta = entry.command().targetPoolSize()
                      - entry.command().currentPoolSize();
            deltasByExecutor
                .computeIfAbsent(entry.executorId(), k -> new ArrayList<>())
                .add(delta);
        }

        for (Map.Entry<String, List<Integer>> e : deltasByExecutor.entrySet()) {
            if (e.getKey().equals(sourceId)) continue;
            List<Integer> deltas = e.getValue();
            // Check alternating signs between source and this executor
            int alternations = 0;
            Integer lastSourceDelta = null;
            Integer lastOtherDelta = null;
            for (int i = recent.size() - 1; i >= 0; i--) {
                GroupCoordinationEntry entry = recent.get(i);
                int delta = entry.command().targetPoolSize()
                          - entry.command().currentPoolSize();
                if (entry.executorId().equals(sourceId)) {
                    if (lastOtherDelta != null
                        && Math.signum(delta) != Math.signum(lastOtherDelta)) {
                        alternations++;
                    }
                    lastSourceDelta = delta;
                } else if (entry.executorId().equals(e.getKey())) {
                    if (lastSourceDelta != null
                        && Math.signum(delta) != Math.signum(lastSourceDelta)) {
                        alternations++;
                    }
                    lastOtherDelta = delta;
                }
            }
            if (alternations >= 2) return true;
        }

        // Pattern 2: Resource ping-pong
        // Same thread units claimed/released between same pair of executors
        Map<String, Integer> pairSwapCount = new HashMap<>();
        for (int i = 0; i < recent.size() - 1; i++) {
            GroupCoordinationEntry a = recent.get(i);
            GroupCoordinationEntry b = recent.get(i + 1);
            if (!a.executorId().equals(b.executorId())) {
                int aDelta = a.command().targetPoolSize() - a.command().currentPoolSize();
                int bDelta = b.command().targetPoolSize() - b.command().currentPoolSize();
                if (Math.signum(aDelta) != Math.signum(bDelta)
                    && Math.abs(aDelta) == Math.abs(bDelta)) {
                    String pair = a.executorId() + "↔" + b.executorId();
                    pairSwapCount.merge(pair, 1, Integer::sum);
                }
            }
        }
        if (pairSwapCount.values().stream().anyMatch(c -> c >= 3)) return true;

        // Pattern 3: Priority thrashing
        // Same source-target preemption pair >= 3 times in window
        Map<String, Integer> preemptCount = new HashMap<>();
        for (GroupCoordinationEntry entry : recent) {
            for (String conflict : entry.result().conflicts()) {
                String pair = entry.executorId() + "→" + conflict.split(":")[0];
                preemptCount.merge(pair, 1, Integer::sum);
            }
        }
        return preemptCount.values().stream().anyMatch(c -> c >= 3);
    }
```

```java
    public static StatisticalSignificance compare(
            double[] modeAValues, double[] modeBValues, String metricName) {

        int n = Math.min(modeAValues.length, modeBValues.length);
        if (n < 2) {
            return new StatisticalSignificance(metricName, 1.0, 0, 0, 0, false, n);
        }

        // Paired differences
        double[] diffs = new double[n];
        for (int i = 0; i < n; i++) {
            diffs[i] = modeAValues[i] - modeBValues[i];
        }

        double meanDiff = mean(diffs);
        double stdErr = stddev(diffs) / Math.sqrt(n);

        if (stdErr < 1e-10) {
            // Zero variance: all differences identical
            return new StatisticalSignificance(metricName, 1.0, meanDiff, meanDiff, 0,
                false, n);
        }

        double t = meanDiff / stdErr;
        double pValue = tDistributionPValue(t, n - 1);

        // Cohen's d
        double pooledStdDev = Math.sqrt(
            ((n - 1) * variance(modeAValues) + (n - 1) * variance(modeBValues))
```

## 4. Concurrency Design

### 4.1 Thread Model

```
AdjustmentLoop-thread-A ──→ CoordinatedAdapter.apply() ──→ GroupCoordinator.coordinate()
                                                                    │
AdjustmentLoop-thread-B ──→ CoordinatedAdapter.apply() ──→ GroupCoordinator.coordinate()
                                                                    │
                                                            synchronized(lock) { ... }
```

- `GroupCoordinator.coordinate()` is `synchronized` on an internal lock — only one coordination decision at a time across all executors
- `ResourceBudget` is `synchronized` on `this` — thread-safe reserve/release for concurrent loop threads
- `GroupCoordinationHistory` uses `CopyOnWriteArrayList` — writes are safe, reads are snapshot-consistent (same pattern as `AdjustmentHistory` in v0.14.0)
- `GroupLoopOrchestrator.loops` uses `ConcurrentHashMap` — concurrent loop management
- Individual `AdjustmentLoop` threads continue to run independently — only the coordination step is serialized
- Fast path: scale-down and no-op decisions acquire the lock briefly (budget check is O(1)) and release immediately

### 4.2 Liveness

- Coordination lock held only for: budget arithmetic + oscillation pattern check + history recording
- No I/O, no network calls, no blocking operations under the lock
- Worst-case lock hold time: O(n) where n = group size (preemption candidate scan), typically < 10 executors → < 1ms
- Deadlock-free: single lock, no nested lock acquisition
- Starvation-free: preemption candidates sorted by priority (lowest first), same-priority FIFO
