## 1. 设计目标

v0.11.0 SR 将已闭环 IR 转成后续 OpenSpec change 可执行的功能设计。目标：在 v0.1.0 的 in-memory metrics 基础和 v0.6.0 的 acquisition 管道基础上，实现持久化证据录制（`FileBackedEvidenceRecorder`）、快照 JSON 序列化（toMap/fromMap + parse）、录制会话生命周期（`RecordingSession`）、以及自主压力采样（`LivePressureSampler`）。

关键架构约束：`FileBackedEvidenceRecorder` 放入 `experiment.acquisition` 包以避免循环依赖（acquisition → metrics 已存在，metrics → acquisition 是新增且会造成循环）。

本设计只描述功能边界和组件契约，不授权 Java 实现，不授权 OpenSpec change 创建。

## 2. 设计结论

- **FileBackedEvidenceRecorder**: 放入 `experiment.acquisition` 包，实现 `EvidenceRecorder`，JSON Lines 文件存储，内存缓冲 + 文件写入双层
- **Snapshot JSON 序列化**: toMap/fromMap 在快照类型自身（`PressureSnapshot`, `RuntimeObservation`, `ObservedSnapshot`），`AcquisitionJsonWriter` 仅新增 `parse()` 方法
- **RecordingSession + RecordingSessionMetadata**: 放入 `experiment.metrics`，会话生命周期管理，`FileBackedEvidenceRecorder` 持有 sessions
- **RuntimeObservation.fromExecutor()**: 静态工厂方法，提取自 `ManagedExecutorScenarioRunner.buildObservation()`
- **LivePressureSampler**: 放入 `experiment.metrics`，实现 `PressureSampler`，`ScheduledExecutorService` 定时采样
- **LivePressureSamplerConfig**: 放入 `experiment.metrics`，采样配置 record
- **ManagedExecutorScenarioRunner 集成**: 新增构造器重载注入 `LivePressureSampler`，向后兼容
- **AcquisitionReportPaths 扩展**: 新增 evidence/session 文件路径方法
- 现有 535 测试零回归

### 关键架构裁决

**Why FileBackedEvidenceRecorder in acquisition**: `AcquisitionJsonWriter` 是 package-private 类，位于 `experiment.acquisition` 包。若 `FileBackedEvidenceRecorder` 放入 `experiment.metrics`，则需要提升 `AcquisitionJsonWriter` 可见性并引入 metrics → acquisition 依赖——而 acquisition 已依赖 metrics（`AcquisitionReportBridge` 接收 `List<ObservedSnapshot>`），这会形成循环依赖。将 `FileBackedEvidenceRecorder` 放入 acquisition 包利用现有依赖方向（acquisition → metrics），无需新增反向依赖。

**Why toMap/fromMap on snapshot types**: 快照类型知道自己的字段结构，序列化/反序列化逻辑与数据放在一起。`AcquisitionJsonWriter` 只做通用的 Map↔JSON 转换，不耦合到具体类型。

## 4. 组件设计

### 4.1 PressureSnapshot 扩展 — toMap / fromMap

**包**: `com.zhiwu.dynamicthreadpollermanager.experiment.model`

**职责**: 提供 Map 表示，支持 JSON 序列化/反序列化。

```java
// 已验证 API 签名:
//   PressureSnapshot(Instant timestamp, int activeThreads, int poolSize,
//                    int queueSize, long completedTaskCount, double cpuUtilization) — 6-field
//   PressureSnapshot(Instant timestamp, int activeThreads, int queueSize, double cpuUtilization) — 4-field
//   访问器: timestamp(), activeThreads(), poolSize(), queueSize(), completedTaskCount(), cpuUtilization()

public Map<String, Object> toMap() {
    Map<String, Object> map = new LinkedHashMap<>();
    map.put("timestamp", timestamp().toString());
    map.put("activeThreads", activeThreads());
    map.put("poolSize", poolSize());
    map.put("queueSize", queueSize());
    map.put("completedTaskCount", completedTaskCount());
    map.put("cpuUtilization", cpuUtilization());
    return map;
}

public static PressureSnapshot fromMap(Map<String, Object> map) {
    Instant timestamp = Instant.parse((String) map.get("timestamp"));
    // 整数 → int, 长整数 → long, 浮点 → double
    int activeThreads = ((Number) map.get("activeThreads")).intValue();
    int poolSize = ((Number) map.get("poolSize")).intValue();
    int queueSize = ((Number) map.get("queueSize")).intValue();
    long completedTaskCount = ((Number) map.get("completedTaskCount")).longValue();
    double cpuUtilization = ((Number) map.get("cpuUtilization")).doubleValue();
    return new PressureSnapshot(timestamp, activeThreads, poolSize,
            queueSize, completedTaskCount, cpuUtilization);
}
```

设计决策：
- `timestamp` 使用 ISO-8601 字符串（`Instant.toString()`），反序列化用 `Instant.parse()`
- 所有数值字段通过 `Number` 基类读取——支持 Integer/Long/Double 三种 JSON number 类型，使用 `.intValue()`/`.longValue()`/`.doubleValue()` 精确转换（处置 IR F01）
- 总是使用 6-field 构造器——`fromMap()` 假设完整数据（`FileBackedEvidenceRecorder` 总是写入完整快照）

### 4.2 RuntimeObservation 扩展 — fromExecutor / toMap / fromMap

**包**: `com.zhiwu.dynamicthreadpollermanager.experiment.metrics`

**职责**: 静态工厂从 live executor 构建观测值 + Map 序列化。

```java
// 已验证 API 签名:
//   ManagedExecutor.getActiveCount() → int
//   ManagedExecutor.getPoolSize() → int
//   ManagedExecutor.getQueueSize() → int
//   ManagedExecutor.getCompletedTaskCount() → long
//   ManagedExecutor.getKeepAliveTime(TimeUnit) → long
//   ManagedExecutor.getLargestPoolSize() → int
//   ManagedExecutor.getTaskCount() → long
//   MetricValue.present(T) → MetricValue<T>
//   MetricValue.absent() → MetricValue<T>
//   RuntimeObservation 9-field constructor:
//     (Instant, MetricValue<Integer>, MetricValue<Integer>, MetricValue<Integer>,
//      MetricValue<Long>, MetricValue<Double>, MetricValue<Long>,
//      MetricValue<Integer>, MetricValue<Long>)

// 处置 IR F03: 提取 buildObservation 逻辑
public static RuntimeObservation fromExecutor(
        com.zhiwu.dynamicthreadpollermanager.experiment.executor.ManagedExecutor executor,
        Instant timestamp) {
    return new RuntimeObservation(
            timestamp,
            MetricValue.present(executor.getActiveCount()),
            MetricValue.present(executor.getPoolSize()),
            MetricValue.present(executor.getQueueSize()),
            MetricValue.present(executor.getCompletedTaskCount()),
            MetricValue.absent(),  // cpuUtilization — no real data source (DFR-01)
            MetricValue.present(executor.getKeepAliveTime(java.util.concurrent.TimeUnit.SECONDS)),
            MetricValue.present(executor.getLargestPoolSize()),
            MetricValue.present(executor.getTaskCount())
    );
}

// Map 序列化
public Map<String, Object> toMap() {
    Map<String, Object> map = new LinkedHashMap<>();
    map.put("timestamp", timestamp().toString());
    map.put("activeThreads", metricValueToMap(activeThreads()));
    map.put("poolSize", metricValueToMap(poolSize()));
    map.put("queueSize", metricValueToMap(queueSize()));
    map.put("completedTaskCount", metricValueToMap(completedTaskCount()));
    map.put("cpuUtilization", metricValueToMap(cpuUtilization()));
    map.put("keepAliveTimeSeconds", metricValueToMap(keepAliveTimeSeconds()));
    map.put("largestPoolSize", metricValueToMap(largestPoolSize()));
    map.put("taskCount", metricValueToMap(taskCount()));
    return map;
}

private static Map<String, Object> metricValueToMap(MetricValue<?> mv) {
    Map<String, Object> m = new LinkedHashMap<>();
    if (mv instanceof MetricValue.Present<?> p) {
        m.put("status", "PRESENT");
        m.put("value", p.value());
    } else {
        m.put("status", "ABSENT");
    }
    return m;
}

public static RuntimeObservation fromMap(Map<String, Object> map) {
    Instant timestamp = Instant.parse((String) map.get("timestamp"));
    return new RuntimeObservation(
            timestamp,
            metricValueFromMap(map, "activeThreads", Integer.class),
            metricValueFromMap(map, "poolSize", Integer.class),
            metricValueFromMap(map, "queueSize", Integer.class),
            metricValueFromMap(map, "completedTaskCount", Long.class),
            metricValueFromMap(map, "cpuUtilization", Double.class),
            metricValueFromMap(map, "keepAliveTimeSeconds", Long.class),
            metricValueFromMap(map, "largestPoolSize", Integer.class),
            metricValueFromMap(map, "taskCount", Long.class)
    );
}

@SuppressWarnings("unchecked")
private static <T> MetricValue<T> metricValueFromMap(
        Map<String, Object> map, String key, Class<T> targetType) {
    Map<String, Object> mvMap = (Map<String, Object>) map.get(key);
    String status = (String) mvMap.get("status");
    if ("ABSENT".equals(status)) {
        return MetricValue.absent();
    }
    Object rawValue = mvMap.get("value");
    T typedValue = targetType.cast(
            targetType == Long.class ? ((Number) rawValue).longValue()
                    : targetType == Integer.class ? ((Number) rawValue).intValue()
                    : targetType == Double.class ? ((Number) rawValue).doubleValue()
                    : rawValue);
    return MetricValue.present(typedValue);
}
```

设计决策：
- `fromExecutor()` 静态工厂（处置 IR F03）——提取自 `ManagedExecutorScenarioRunner.buildObservation()`，后者委托给此方法
- `cpuUtilization` 始终 absent——DFR-01，预留扩展点
- `toMap()` 中将 `MetricValue` 表示为 `{"status": "PRESENT"/"ABSENT", "value": ...}`（decision-log D6）
- `fromMap()` 通过 `targetType` 参数精确转换 JSON number 类型，避免 Integer/Long 混淆（处置 IR F01）
- 线程安全：所有 `ManagedExecutor` getter 返回近似瞬时值，在多线程环境下安全（处置 IR F05）

### 4.5 RecordingSession + RecordingSessionMetadata

**包**: `com.zhiwu.dynamicthreadpollermanager.experiment.metrics`

**职责**: 录制会话生命周期管理。

```java
public enum SessionStatus { ACTIVE, CLOSED }

public final class RecordingSession {
    private final String sessionId;
    private final String runId;
    private final ManagedExecutorConfig executorConfig;  // 会话开始时的配置快照
    private final Instant startedAt;
    private volatile Instant closedAt;
    private volatile int snapshotCount;
    private volatile SessionStatus status;

    public RecordingSession(String sessionId, String runId,
                            ManagedExecutorConfig executorConfig) {
        this.sessionId = java.util.Objects.requireNonNull(sessionId);
        this.runId = java.util.Objects.requireNonNull(runId);
        this.executorConfig = java.util.Objects.requireNonNull(executorConfig);
        this.startedAt = Instant.now();
        this.status = SessionStatus.ACTIVE;
    }

    public void incrementSnapshotCount() {
        if (status != SessionStatus.ACTIVE) {
            throw new IllegalStateException("session is not ACTIVE");
        }
        snapshotCount++;
    }

    public RecordingSessionMetadata close() {
        if (status != SessionStatus.ACTIVE) {
            throw new IllegalStateException("session is already CLOSED");
        }
        this.closedAt = Instant.now();
        this.status = SessionStatus.CLOSED;
        return new RecordingSessionMetadata(
                sessionId, runId, executorConfig,
                startedAt, closedAt, snapshotCount, status);
    }

    // accessors: sessionId(), runId(), executorConfig(), startedAt(),
    //            closedAt(), snapshotCount(), status()
}
```

```java
public record RecordingSessionMetadata(
        String sessionId,
        String runId,
        com.zhiwu.dynamicthreadpollermanager.experiment.executor.ManagedExecutorConfig executorConfig,
        java.time.Instant startedAt,
        java.time.Instant closedAt,
        int snapshotCount,
        SessionStatus status
) {}
```

设计决策：
- 放入 `experiment.metrics`（不依赖 acquisition，无循环依赖）
- `sessionId` 由 `FileBackedEvidenceRecorder` 在 `startSession()` 中生成（UUID.randomUUID().toString()）
- `ManagedExecutorConfig` 作为配置快照——会话开始时记录，不可变（record）
- 二次 close() 抛 `IllegalStateException`（防御性保护）

### 4.6 FileBackedEvidenceRecorder

**包**: `com.zhiwu.dynamicthreadpollermanager.experiment.acquisition`

**职责**: 实现 `EvidenceRecorder`，将 `ObservedSnapshot` 持久化为 JSON Lines 文件。

```java
// 已验证 API 签名:
//   EvidenceRecorder.record(ObservedSnapshot) → void
//   EvidenceRecorder.snapshots(String) → List<ObservedSnapshot>
//   EvidenceRecorder.runIds() → Set<String>
//   AcquisitionReportPaths.forVersion(String) → AcquisitionReportPaths
//   AcquisitionReportPaths.outputDirectory() → String

public final class FileBackedEvidenceRecorder implements EvidenceRecorder {

    private final Path outputDir;
    private final ConcurrentHashMap<String, List<ObservedSnapshot>> buffer;
    private final ConcurrentHashMap<String, RecordingSession> sessions;

    public FileBackedEvidenceRecorder(Path outputRoot, String versionTag) {
        // 委托 AcquisitionReportPaths 管理版本化目录 (处置 SR F03)
        AcquisitionReportPaths paths = AcquisitionReportPaths.forVersion(versionTag);
        this.outputDir = outputRoot.resolve(paths.outputDirectory());
        this.buffer = new ConcurrentHashMap<>();
        this.sessions = new ConcurrentHashMap<>();
        // 确保输出目录存在
        try {
            java.nio.file.Files.createDirectories(outputDir);
        } catch (java.io.IOException e) {
            throw new java.io.UncheckedIOException(e);
        }
    }

    // ----- EvidenceRecorder implementation -----

    @Override
    public void record(ObservedSnapshot snapshot) {
        java.util.Objects.requireNonNull(snapshot, "snapshot must not be null");
        String runId = snapshot.runId();

        // 1. 先更新内存缓冲 (处置 IR F04: write-before-file)
        buffer.computeIfAbsent(runId, k ->
                new java.util.concurrent.CopyOnWriteArrayList<>()).add(snapshot);

        // 2. 增量更新会话计数器 (处置 SR F01: 仅在 ACTIVE 时递增)
        RecordingSession session = sessions.get(runId);
        if (session != null && session.status() == SessionStatus.ACTIVE) {
            session.incrementSnapshotCount();
        }

        // 3. 追加写入 JSON Lines 文件
        try {
            String json = renderSnapshot(snapshot);
            Path evidenceFile = evidenceFilePath(runId);
            java.nio.file.Files.writeString(evidenceFile, json + "\n",
                    java.nio.file.StandardOpenOption.CREATE,
                    java.nio.file.StandardOpenOption.APPEND);
        } catch (java.io.IOException e) {
            throw new java.io.UncheckedIOException(
                    "failed to write evidence for runId=" + runId, e);
        }
    }

    @Override
    public List<ObservedSnapshot> snapshots(String runId) {
        java.util.Objects.requireNonNull(runId, "runId must not be null");
        List<ObservedSnapshot> recorded = buffer.get(runId);
        if (recorded == null) {
            return Collections.emptyList();
        }
        return List.copyOf(recorded);
    }

    @Override
    public Set<String> runIds() {
        return Set.copyOf(buffer.keySet());
    }

    // ----- Session management -----

    public RecordingSession startSession(String runId,
            com.zhiwu.dynamicthreadpollermanager.experiment.executor.ManagedExecutorConfig config) {
        java.util.Objects.requireNonNull(runId);
        java.util.Objects.requireNonNull(config);
        if (sessions.containsKey(runId)) {
            RecordingSession existing = sessions.get(runId);
            if (existing.status() == SessionStatus.ACTIVE) {
                throw new IllegalStateException(
                        "active session already exists for runId=" + runId);
            }
        }
        String sessionId = java.util.UUID.randomUUID().toString();
        RecordingSession session = new RecordingSession(sessionId, runId, config);
        sessions.put(runId, session);
        return session;
    }

    public RecordingSessionMetadata closeSession(String runId) {
        java.util.Objects.requireNonNull(runId);
        RecordingSession session = sessions.get(runId);
        if (session == null) {
            throw new IllegalStateException("no session for runId=" + runId);
        }
        RecordingSessionMetadata metadata = session.close();
        flush(runId);  // flush before writing metadata
        writeSessionMetadata(metadata);
        return metadata;
    }

    public void flush(String runId) {
        // 当前实现中 record() 已即时写入文件——flush 是 no-op
        // 保留此方法为未来批量写入优化留接口
    }

    // ----- Private helpers -----

    private String renderSnapshot(ObservedSnapshot snapshot) {
        Map<String, Object> map = snapshot.toMap();
        return AcquisitionJsonWriter.render(map);
    }

    private Path evidenceFilePath(String runId) {
        return outputDir.resolve(AcquisitionReportPaths.evidenceFileName(runId));
    }

    private Path sessionMetadataPath(String runId) {
        return outputDir.resolve(AcquisitionReportPaths.sessionMetadataFileName(runId));
    }

    private void writeSessionMetadata(RecordingSessionMetadata metadata) {
        Map<String, Object> map = sessionMetadataToMap(metadata);
        String json = AcquisitionJsonWriter.render(map);
        try {
            java.nio.file.Files.writeString(sessionMetadataPath(metadata.runId()), json);
        } catch (java.io.IOException e) {
            throw new java.io.UncheckedIOException(
                    "failed to write session metadata for runId=" + metadata.runId(), e);
        }
    }

    private Map<String, Object> sessionMetadataToMap(RecordingSessionMetadata m) {
        Map<String, Object> map = AcquisitionJsonWriter.map();
        map.put("sessionId", m.sessionId());
        map.put("runId", m.runId());
        map.put("executorConfig", executorConfigToMap(m.executorConfig()));
        map.put("startedAt", m.startedAt().toString());
        map.put("closedAt", m.closedAt().toString());
        map.put("snapshotCount", m.snapshotCount());
        map.put("status", m.status().name());
        return map;
    }

    private Map<String, Object> executorConfigToMap(
            com.zhiwu.dynamicthreadpollermanager.experiment.executor.ManagedExecutorConfig config) {
        Map<String, Object> map = AcquisitionJsonWriter.map();
        map.put("corePoolSize", config.corePoolSize());
        map.put("maximumPoolSize", config.maximumPoolSize());
        map.put("queueCapacity", config.queueCapacity());
        map.put("keepAliveTime", config.keepAliveTime());
        map.put("keepAliveTimeUnit", config.keepAliveTimeUnit().name());
        return map;
    }

    private static String safeRunId(String runId) {
        // same validation as AcquisitionReportPaths.requireSafeRunId
        java.util.Objects.requireNonNull(runId);
        if (runId.isBlank()) throw new IllegalArgumentException("runId must not be blank");
        if (runId.contains("/") || runId.contains("\\") || runId.contains(".."))
            throw new IllegalArgumentException("runId contains path traversal");
        return runId;
    }
}
```

### 4.8 LivePressureSampler

**包**: `com.zhiwu.dynamicthreadpollermanager.experiment.metrics`

**职责**: 实现 `PressureSampler`，按固定间隔从 live executor 自主采样。

```java
// 已验证 API 签名:
//   PressureSampler.sample(String runId, RuntimeObservation, Instant) → ObservedSnapshot
//   SnapshotAssembler.assemble(String runId, RuntimeObservation) → ObservedSnapshot
//   DefaultSnapshotAssembler 无参构造器
//   ManagedExecutor: getActiveCount(), getPoolSize(), getQueueSize(),
//     getCompletedTaskCount(), getKeepAliveTime(TimeUnit), getLargestPoolSize(),
//     getTaskCount() — 所有 getter 线程安全 (处置 IR F05)

public final class LivePressureSampler implements PressureSampler {

    private final com.zhiwu.dynamicthreadpollermanager.experiment.executor.ManagedExecutor executor;
    private final EvidenceRecorder recorder;
    private final SnapshotAssembler assembler;
    private final LivePressureSamplerConfig config;
    private final java.util.concurrent.ScheduledExecutorService scheduler;
    private final java.util.concurrent.atomic.AtomicBoolean running =
            new java.util.concurrent.atomic.AtomicBoolean(false);
    private final java.util.concurrent.atomic.AtomicInteger consecutiveFailures =
            new java.util.concurrent.atomic.AtomicInteger(0);
    private static final int MAX_CONSECUTIVE_FAILURES = 10;

    public LivePressureSampler(
            com.zhiwu.dynamicthreadpollermanager.experiment.executor.ManagedExecutor executor,
            EvidenceRecorder recorder,
            SnapshotAssembler assembler,
            LivePressureSamplerConfig config) {
        this.executor = java.util.Objects.requireNonNull(executor);
        this.recorder = java.util.Objects.requireNonNull(recorder);
        this.assembler = java.util.Objects.requireNonNull(assembler);
        this.config = java.util.Objects.requireNonNull(config);
        this.scheduler = java.util.concurrent.Executors.newSingleThreadScheduledExecutor(
                r -> {
                    Thread t = new Thread(r, "live-pressure-sampler-" + config.sessionId());
                    t.setDaemon(true);
                    return t;
                });
    }

    public LivePressureSampler(
            com.zhiwu.dynamicthreadpollermanager.experiment.executor.ManagedExecutor executor,
            EvidenceRecorder recorder,
            LivePressureSamplerConfig config) {
        this(executor, recorder, new DefaultSnapshotAssembler(), config);
    }

    public void start(String runId) {
        java.util.Objects.requireNonNull(runId);
        if (!running.compareAndSet(false, true)) {
            throw new IllegalStateException("sampler is already running");
        }
        scheduler.scheduleWithFixedDelay(() -> {
            if (!running.get()) return;
            try {
                Instant now = Instant.now();
                RuntimeObservation obs = RuntimeObservation.fromExecutor(executor, now);
                ObservedSnapshot snapshot = assembler.assemble(runId, obs);
                recorder.record(snapshot);
                consecutiveFailures.set(0);  // 成功时重置计数器
            } catch (RuntimeException e) {
                int failures = consecutiveFailures.incrementAndGet();
                // log at WARN level
                if (failures >= MAX_CONSECUTIVE_FAILURES) {
                    // log at ERROR level: circuit breaker tripped
                    stop();
                }
            }
        }, 0, config.pollIntervalMs(), java.util.concurrent.TimeUnit.MILLISECONDS);
    }

    public void stop() {
        if (!running.compareAndSet(true, false)) {
            return; // already stopped, idempotent
        }
        scheduler.shutdown();
        try {
            if (!scheduler.awaitTermination(10, java.util.concurrent.TimeUnit.SECONDS)) {
                scheduler.shutdownNow();
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            scheduler.shutdownNow();
        }
    }

    public boolean isRunning() {
        return running.get();
    }

    @Override
    public ObservedSnapshot sample(String runId, RuntimeObservation observation, Instant at) {
        java.util.Objects.requireNonNull(runId);
        java.util.Objects.requireNonNull(observation);
        java.util.Objects.requireNonNull(at);
        RuntimeObservation timestamped = observation.withTimestamp(at);
        ObservedSnapshot snapshot = assembler.assemble(runId, timestamped);
        recorder.record(snapshot);
        return snapshot;
    }
}
```

```java
// 已验证 API 签名: 无特殊依赖 — 纯数据 record

public record LivePressureSamplerConfig(
        long pollIntervalMs,
        boolean autoStart,
        String sessionId
) {
    public LivePressureSamplerConfig {
        if (pollIntervalMs < 100) {
            throw new IllegalArgumentException(
                    "pollIntervalMs must be >= 100, was " + pollIntervalMs);
        }
        java.util.Objects.requireNonNull(sessionId);
    }

    public static LivePressureSamplerConfig defaults(String sessionId) {
        return new LivePressureSamplerConfig(1000, false, sessionId);
    }
}
```

设计决策：
- `scheduleWithFixedDelay()`（决策 D3）——固定延迟，前一次采样完成后才调度下一次
- daemon 线程——JVM 退出时自动停止，不阻塞 shutdown
- `AtomicBoolean.compareAndSet()` 保证 `start()`/`stop()` 原子性——防止 TOCTOU 竞态和重复启动 (处置 SR F04)
- 连续失败计数器 + 熔断：`MAX_CONSECUTIVE_FAILURES = 10`，超过阈值自动 `stop()` (处置 SR F05)
- 单次采样异常 log 并递增失败计数——成功采样后重置计数器
- `sample()` 仍可用——与自主调度共存，手动采样直接写入 recorder
- `stop()` 先 `compareAndSet(true, false)`——idempotent，重复调用安全
- 最小间隔 100ms——防止 CPU 空转
