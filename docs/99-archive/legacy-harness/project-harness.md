## Rule of Precedence

For project work:

1. Harness defines durable governance.
2. Architecture defines living target-system design.
3. Delivery Framework defines toolchain and review mechanics.
4. V1 design documents define the bounded first-version scope and authorized execution sequence.
5. A future approved OpenSpec/SuperSpec change defines bounded delivery scope.
6. Roadmaps and candidate capability lists do not prove implementation.
