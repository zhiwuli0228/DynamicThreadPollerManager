# OpenSpec

This directory defines the lifecycle rules that govern OpenSpec artifacts and version-to-change authorization.

## Documents

1. `docs/03-openspec/artifact-boundary.md`
2. `docs/03-openspec/lifecycle-rule.md`
3. `docs/03-openspec/version-design-to-change-rule.md`

## Rule

- No `openspec/changes/**` may be created until a version design explicitly authorizes change decomposition or execution.
