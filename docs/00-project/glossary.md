# Glossary

## Core Terms

- `Context Hub`: the numbered documentation structure that carries authoritative project context.
- `Current State`: the single record that says which stage is authorized right now.
- `Living Architecture`: the long-lived target-system model that guides future design.
- `Harness`: the governance rules for AI behavior, context reading, execution, and verification.
- `OpenSpec`: the lifecycle system for proposal, design, tasking, apply, verify, and finalize artifacts.
- `Version Design`: a bounded future release design package that may later authorize change decomposition.
- `Change Decomposition`: the step that turns an authorized version design into one or more bounded OpenSpec changes.
- `Archive`: historical material that no longer acts as current authority.

## Domain Terms

- `Managed executor`: the executor abstraction that future version work may design and operate.
- `Workload`: a bounded scenario used to exercise or observe the managed executor behavior.
- `Observability surface`: metrics, logs, or traces that expose system behavior for inspection.
- `Execution boundary`: the line that separates a document-only framework stage from implementation authorization.
