# Harness Standard

## Non-Negotiables

- Respect the current stage in `docs/00-project/current-state.md`.
- Do not create version designs or OpenSpec changes before authorization.
- Do not invent scope from archived bootstrap material.
- Record real validation evidence.
- Keep file changes within the allowed boundary of the active task.

## Working Principle

- Documentation framework tasks may reorganize the context hub.
- Capability work is never implied by a framework task.
