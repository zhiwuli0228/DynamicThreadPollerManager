# Executor Domain Glossary

## Terms

- `Managed executor`: the named executor instance or definition that the system controls.
- `Executor registry`: the storage and lookup boundary for managed executors.
- `Workload scenario`: a bounded execution pattern used to exercise the system.
- `Deletion safety`: rules that prevent unsafe removal of a live executor.
- `Observability probe`: a metric, log, or trace point that reveals executor state or behavior.
- `Runtime update`: a controlled change to a permitted executor field.

## Rule

- Use the domain glossary when writing future version designs so the same term keeps the same meaning.
