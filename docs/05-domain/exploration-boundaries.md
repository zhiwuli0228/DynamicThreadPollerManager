# Exploration Boundaries

## In Scope for Exploration

- Managed executor behavior.
- Bounded workload execution.
- Safety semantics for executor updates and deletion.
- Observability and experiment surfaces.

## Out of Scope Until Later Design

- Redis.
- Kafka.
- Database persistence.
- Frontend.
- Authentication.
- Multi-node coordination.
- Virtual threads as a default execution mode.

## Rule

- Exploration boundaries are not implementation authorization.
